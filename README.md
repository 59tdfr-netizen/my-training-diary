# Мой тренировочный дневник

Готовое одностраничное приложение для ведения дневника силовых тренировок.
Работает без сервера, без регистрации, без платных API.

## Запуск (без терминала)

1. Скачайте все файлы в одну папку (например, `training-diary`).
2. Откройте `index.html` двойным кликом в браузере (Chrome, Edge, Firefox, Safari).
3. Готово.

## Установка как приложение (PWA, по желанию)

Работает только при открытии через HTTP(S), не через `file://`.
Самый простой способ без терминала — загрузить папку на любой бесплатный статический хостинг
(например, GitHub Pages, Netlify Drop) и открыть ссылку. Затем в браузере:
«Меню → Установить приложение» / «Добавить на главный экран».

## Как пользоваться

- **Главная** — сводка прогресса, правила, карточки тренировочных дней.
- **Начать тренировку** — открывает экран занятия. Вводите вес и повторения по подходам.
  - «Без веса» — для упражнений без отягощения.
  - «Разные веса по подходам» — если вес меняется между подходами.
  - Вес подставляется из последней тренировки этого упражнения — можно изменить.
- **Завершить тренировку** — показывает сводку, предупреждает о пропущенных упражнениях,
  сохраняет запись в историю. Черновик тренировки сохраняется автоматически: можно закрыть вкладку и вернуться.
- **История** — список, поиск по упражнению, фильтр по датам, просмотр и редактирование записи,
  удаление записи, прогресс по конкретному упражнению с графиком.
- **Редактировать программу** — добавить/удалить/переименовать дни и упражнения, изменить порядок,
  подходы, повторения, единицы (кг / повторы / секунды), стартовый вес. История не затрагивается.
- **Загрузить новую программу** — загрузить фото и вручную заполнить новую программу.
  Старая программа уходит в архив, история остаётся.
- **Резервная копия** — экспорт в JSON, импорт с предпросмотром и подтверждением, полный сброс.

## Резервное копирование

1. Откройте «Резервная копия» → «Скачать резервную копию».
2. Файл `trenirovki-backup-ГГГГ-ММ-ДД.json` сохранится в загрузки.
3. Для восстановления: «Резервная копия» → «Импорт» → выберите файл → проверьте предпросмотр → подтвердите.

**Важно:** данные хранятся в `localStorage` браузера. Очистка кэша, режим инкогнито
или другое устройство приведут к потере. Регулярно экспортируйте копию.

## Замена программы с помощью фото

1. «Загрузить новую программу» → выберите фото.
2. «Заполнить программу по фото» — откроется редактор с текущей программой как основой,
   фото будет показано сверху для сверки.
3. Отредактируйте дни/упражнения по фото.
4. «Сохранить» → подтвердите замену. Старая программа уйдёт в архив, история сохранится.

Автоматическое распознавание текста с фото без внешнего платного API невозможно,
поэтому используется ручное заполнение с предпросмотром. Это честно и безопасно.

## Ограничения

- Нет OCR: распознавание фото — только вручную.
- Нет облачной синхронизации: данные локальные, перенос через JSON.
- PWA (установка) требует HTTP(S), не работает через `file://`.
